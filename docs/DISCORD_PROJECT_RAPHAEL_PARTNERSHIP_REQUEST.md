# Project Raphael — Discord partnership consultation

## Subject

**Can Discord enable a new kind of experience creator: the DISCORDER?**

## Send-ready message

Hello Discord Developer Platform Team,

Imagine a player staying fully immersed in a game and asking through smartphone Discord:

> “Raphael, which item should I use in this battle?”

The AI sees only the authorized game window and answers through Discord voice. While the player continues playing, it can handle explicitly permitted work outside the game—such as replying to an important email—pause a robot vacuum, optimize the air conditioner, and change Home Assistant lighting for a battle or a brighter post-battle break.

For a new game, Raphael can explain initial setup, controls and skills at the moment they are needed, reducing the need to stop playing and search a wiki. For a team, it can record an authorized boss battle, replay the previous attempt before the next fight, and compare timing, positioning and item usage afterward.

We call the human creator of this experience a **DISCORDER**. A DISCORDER combines games, community preferences, lifestyle information and relevant purchase guidance into a participatory Discord experience. Unlike a one-way broadcaster, the DISCORDER interacts with the community and provides support matched to each participant and moment.

**Project Raphael** is the AI platform that supports the DISCORDER with research, personalization, operation and authorized actions. **Discodex** is Raphael's open-source Discord module, responsible for the mobile entrypoint, permission validation, voice/video transport and participant controls. Discodex already provides validated bidirectional Codex voice through Discord on Android and iPhone.

The product is not intended for hacking or cheating. It will not read game memory, inject code, automate controls, inspect private traffic, bypass anti-cheat, expose hidden information or play without the user. Games or competitive modes that prohibit external assistance will use post-match analysis only.

Discord is uniquely suited to this creator model because identity, roles, voice, video, commands and entitlements let a DISCORDER deliver interactive, personalized and premium experiences directly to a community. Permission validation and audit remain internal safety mechanisms of Raphael rather than additional public-facing roles.

The missing component is an officially supported way for the authorized bot itself to publish the selected game or application capture through Go Live. We will not automate a normal Discord account, use a user token or rely on undocumented protocol behavior.

We are not asking only for a protocol answer. We are looking for a Discord Product or Developer Platform team interested in discussing the DISCORDER creator model and Project Raphael as a limited pilot. We can provide the open-source voice bridge, Android/iPhone/Windows evidence, permission model, DAVE findings, prototype environment and anonymized pilot measurements.

Would Discord be interested in discussing the appropriate architecture and whether an approved bot-owned Go Live path, Developer Preview or partnership route is available?

## 日本語要旨

DISCORDERは、ゲーム、communityの趣向、生活情報、衣食住に関する購入提案を組み合わせ、Discord上で参加型体験を提供する人間のcreatorである。Project RaphaelはDISCORDERの調査、個別最適化、運営、許可済み作業をAIで支援する。DiscodexはスマホDiscordからRaphaelを利用するentrypoint、権限検証、音声・映像transport、参加者UIを担当するmoduleである。Discordへは、DISCORDER creator modelの限定pilotと、通常ユーザーを自動操作しないbot-owned Go Liveの公式経路を相談する。
